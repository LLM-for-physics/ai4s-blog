# 公钥提交指南

完成邮箱验证并上传公钥后，公钥会导入名单中为你分配的课程服务器。助教开启自动导入时，开启后新提交的首次公钥和替换公钥会自动处理；未开启时等待助教人工确认。服务器账号由管理员另外准备；网站显示“已提交”时，公钥尚不一定已经导入。

[打开公钥提交页面](/course/ssh-keys)

## 1. 准备一把 SSH 密钥

### 先找已有密钥

先在自己的电脑上打开 SSH 密钥的默认保存目录，查找 `.pub` 公钥及其对应的私钥：

- **Windows**：默认在 `C:\Users\你的用户名\.ssh\`。可在文件资源管理器或选择文件窗口的地址栏输入 `%USERPROFILE%\.ssh`。
- **macOS**：默认在 `~/.ssh/`。在访达或选择文件窗口中按 `Command + Shift + G`，输入 `~/.ssh` 即可打开。
- **Linux**：默认在 `~/.ssh/`。在文件管理器或选择文件窗口中进入该目录；看不到 `.ssh` 时，请启用“显示隐藏文件”。

常见的文件对是 `id_ed25519` 和 `id_ed25519.pub`，或 `id_rsa` 和 `id_rsa.pub`。不带 `.pub` 的是私钥，应留在自己的电脑上；带 `.pub` 的是公钥，用于上传。

**如果已有 Ed25519 公钥或至少 3072 位的 RSA 公钥，并且仍保留对应私钥，就可以直接使用，无需重新生成。** 记下公钥的位置和文件名，继续第 2 节验证学校邮箱。已有密钥也可以使用其他文件名，关键是公钥和私钥必须对应。

### 没有可用密钥时再生成

如果没有可用的密钥对，在 Windows PowerShell、macOS 终端或 Linux 终端中运行：

```sh
ssh-keygen -t ed25519
```

按提示选择保存位置。使用默认位置和文件名时，会生成以下两个文件：

| 文件 | 用途 |
| --- | --- |
| `id_ed25519` | 私钥，留在自己的电脑上 |
| `id_ed25519.pub` | 公钥，上传到课程网站 |

如果提示文件已经存在或询问 `Overwrite (y/n)?`，先输入 `n`，不要直接覆盖正在使用的密钥。可以使用已有密钥，或改用新文件名生成课程专用密钥。

**一般可以不设置本地私钥的保护口令。** 出现 `Enter passphrase (empty for no passphrase):` 时直接回车，随后在 `Enter same passphrase again:` 提示下再次回车，即可跳过口令设置。

如果选择设置口令，它用于解锁本机私钥，**不是学校邮箱密码，也不是服务器登录密码**；输入时不会显示字符。

## 2. 验证学校邮箱

1. 打开[公钥提交页面](/course/ssh-keys)，输入完整学号，包括开头的零。
2. 点击“发送验证码”。验证码发送到 `学号@stu.pku.edu.cn`。
3. 登录自己的学校邮箱，找到验证码邮件，在十分钟内填写六位验证码。

目前已向所有在册学生开放公钥提交。只有选课名单中的学生可以验证登录；已移除或未录入名单的人员不能提交。如果迟迟收不到邮件，请检查垃圾邮件，并请助教核对学号是否已录入名单。网站不会要求输入学校邮箱的密码。

## 3. 上传 `.pub` 文件

选择第 1 节中找到或生成的 `.pub` 公钥文件，点击“提交公钥”。文件名可以是 `id_ed25519.pub`、`id_rsa.pub`，也可以是你自行设置的其他 `.pub` 文件名。

**请只上传公钥文件，不要上传不带 `.pub` 后缀的私钥文件。** 文件内应只有一把公钥，大小不超过 4 KiB。网站会检查内容，文件名正确但内容不合格时也会拒绝。

提交成功后可以查看算法、指纹和完整公钥。页面显示“已导入”后，使用对应的本地私钥登录；请始终妥善保留私钥。自动导入只处理开关开启后新提交的公钥，不会因开启开关自动导入此前保存的公钥。重复提交同一把公钥不会将旧提交变成新的自动任务，已有提交可请助教人工导入。

## 4. 查看状态并登录

| 页面状态 | 含义与下一步 |
| --- | --- |
| 待助教审核 | 公钥已保存，等待助教人工确认导入 |
| 等待自动导入 | 后台正在检查账号及授权；准备好后自动继续，无需重传 |
| 账号不存在，待创建 | 公钥已保存；账号及授权准备好后，等待中的自动任务会继续检查，助教也可人工导入 |
| 待管理员授权 | 服务器账号尚未完成授权准备，等待助教处理 |
| 等待导入 / 正在导入 | 后台正在处理；页面可见时自动刷新，也可点击“刷新状态” |
| 自动导入暂时受阻 / 已取消 | 查看页面原因并联系助教；公钥记录仍会保留 |
| 自动导入已暂停 | 助教撤销过课程公钥，重新上传不会解除暂停；请联系助教人工导入或恢复 |
| 已导入 | 公钥已写入服务器，可以尝试 SSH 登录 |
| 导入失败 | 查看错误说明并联系助教，公钥记录仍会保留 |
| 已撤销 | 当前课程公钥已撤销，恢复使用请联系助教 |

后台自动导入要求目标 Linux 账号已经存在并由 root 管理员完成授权。网站不会自行创建账号。助教停止自动导入时，尚未批准的候选会取消，已进入导入队列的任务仍会完成。

服务器由助教在选课名单中分配，可能为 132、190 或 197；学生不能自行选择或修改。登录用户名统一为 `stu` 加完整学号，例如学号 `0012345678` 对应 `stu0012345678`。学校邮箱仍为 `0012345678@stu.pku.edu.cn`，不加 `stu` 前缀。

三台服务器均已启用公钥安装通道，SSH 端口统一为 `2024`：132 对应 `162.105.151.132`，190 对应 `162.105.151.190`，197 对应 `162.105.151.197`。请连接页面分配给自己的服务器。

完整的 Windows / macOS / Linux 密钥生成、SSH 配置和 VS Code 连接步骤见[服务器使用指南](https://aiphy.pku.edu.cn/setup/server)。若你已配置好密钥，连接命令的基本形式是：

```sh
ssh -p 2024 stu你的学号@你的服务器IP
```

将命令中的学号和 IP 替换为自己的实际信息。使用自定义文件名的密钥时，需要在 SSH `config` 的 `IdentityFile` 中填写对应**本地私钥**路径，或通过 `-i` 指定它；不能填写 `.pub` 路径。

首次连接时，如果询问是否继续连接，输入 `yes` 并回车。公钥已经导入，但登录仍失败时，把错误提示发给助教即可，无需提供私钥。

## 名单移除与恢复

退课或名单调整后，助教可能将你从在册名单移除。移除后不能继续验证登录或提交，已经保存的历史记录会保留。如果需要重新加入课程，请联系助教明确恢复名单，再重新验证邮箱；恢复名单不会自动安装公钥。

## 更换电脑或更换公钥

在提交页面上传新的 `.pub` 文件。自动导入开启后，新提交的替换公钥也会自动处理；未开启时等待助教人工导入。导入成功前原课程公钥继续有效，成功后由新公钥替换；请使用新公钥对应的私钥登录。

如果助教手动撤销过你的课程公钥，自动导入会暂停。重新上传不会自动恢复访问，只有助教人工导入或恢复公钥成功后才解除暂停。

每人只有一把由本系统管理的当前课程公钥。重复上传同一把公钥不会产生额外版本。

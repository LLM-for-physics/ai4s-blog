# 提交方式

## 第一次作业

**截止日期：2026 年 10 月 3 日 23:59。**

请在服务器上的个人目录下建立一个 `homework1` 文件夹，然后将你的作业代码全部放在该文件夹。

提交内容包括：

- **程序代码**：包含运行入口及必要的额外依赖说明，最好能够在服务器上的 pubpy 环境下直接运行。
- **README.md**：简要说明运行方法和实现思路。

如果使用了 AI 辅助开发，请在 README 中简要说明所用模型的具体型号、使用平台、消耗的额度/token，以及自己进行了哪些验证。如果完全没有使用 AI，可以备注“纯手搓”。


## 第二次作业

**截止日期：2026 年 10 月 10 日 23:59。**

请在服务器个人目录下建立一个 `homework2` 文件夹，将以下材料放在该文件夹中：

- **三个 Skill 文件夹**：包含 `SKILL.md` 及实际使用的脚本、资料等，能够完整运行。
- **一份 README**：分别说明每个 Skill 解决的问题、原来的人工做法、现在的使用方法与节省的时间，以及必要的人工介入。说明三个 Skills 各自的职责与划分理由；参考已有 Skill 时，注明来源、具体修改及其与个人需求的关系。
- **创建记录文件夹**：三个 Skills 各自创建过程的完整 AI 对话，包括调试与修改。
- **运行记录文件夹**：每个 Skill 至少提供一个完成对应任务的完整运行对话记录，并附必要的输入与输出文件；此类输入与输出文件总大小不超过 **100 MB**，数据类文件可提供部分示例。

每份创建或运行记录注明**模型、平台、成本开销**（平台显示的 token 或 API-Key 费用）。未显示的数据写“平台未提供”；估算值注明依据。

记录应保留对应任务从开始到结束的用户消息、AI 回复，可以导出为 Markdown 或 PDF，不能只交摘要或结果截图。多个 Skills 在同一大型任务会话中创建或协作运行，可以共用一份完整记录，标明各自对应的位置与作用，无需重复提交。

**提交前对会话记录中的隐私数据和密钥脱敏，或用占位符替代，并保留过程的可理解性。**

本次作业在自己的电脑上开发即可，无需使用课程服务器的计算资源；完成后将提交材料上传到服务器。完整要求与材料见[作业 2：Skills 的使用](./assignment-2)。

## 第三次作业

**截止时间：2026 年 10 月 30 日 23:59（北京时间）。**

请将以下四个文件放入服务器个人主目录的 `~/homework3/` 文件夹：

- **补全后的代码**：`addition.py`、`pinn.py`。

代码应能在服务器的 `pubpy` 环境中运行，不提交缓存文件。比较分析选交，不计分；谐振子拓展案例不属于必做任务，也不计分。

完整题目、评分标准与材料见[作业 3：神经网络学习加法与 PINN 求解静电势](./assignment-3)。

后续作业的提交要求将在发布时补充。

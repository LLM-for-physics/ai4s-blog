# README 写作提示

在自己的 `homework1` 中写一份简短的 `README.md`，说明以下内容，以实际实现和验证结果为准。

- **运行方法**：Python 环境、必要依赖、入口文件、API 配置，以及启动和浏览器访问方式。不要写真实 Key。
- **实现思路**：消息如何表示，历史在哪里保存，怎样选中和新建会话，为什么不会混入旧内容。
- **保存范围**：刷新、切换、新建和重启分别怎样影响记录。
- **验证结果**：写实际操作、结果和仍存在的问题，不要把教程的预期结果当成自己的记录。
- **AI 辅助开发**：写帮助编程的模型具体型号、平台、消耗的额度或 token，以及自己做过的验证；多个模型或平台分别记录。这与程序聊天接口使用哪个模型不是同一件事。

及时记录 AI 用量，以平台实际信息为准。平台不显示时如实说明，并向助教确认登记方式，不要编造数值。完全没有使用 AI 时，按要求备注“纯手搓”。

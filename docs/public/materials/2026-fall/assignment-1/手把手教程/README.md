# 第一次作业：从网页骨架逐步完成对话程序

你将从一个已经能打开网页的小程序出发，亲手把它完善成自己的作业。

可以先打开本包的 PDF 小册子集中阅读；操作时先阅读[运行指南](运行指南.md)，把 [app.py](app.py) 跑起来；然后跟着[从骨架到多轮对话](从骨架到多轮对话.md)逐步修改这个文件。每完成一个环节，先运行、观察，再继续。

起始 `app.py` 只接收输入、显示演示回复。真实 API、连续对话、历史记录和新建会话，都需要你在学习中实现。教程会解释改动位置、数据流向和新知识，提供必要的局部示例；包内只有这一份起始代码，没有完成后的整份程序。

本路线使用 Python、Flask、Requests，加上一小段放在 Python 字符串中的 HTML。所需 HTML 会随用随讲，不需要先学习一个完整的前端框架。

这是个人学习程序的一种实现路线。教程先用内存中的列表保存历史，重启程序后会丢失；你可以选择进一步保存到文件，并在 README 中如实说明。正式要求以课程发布内容为准，教程中的实现建议不额外增加评分条件。

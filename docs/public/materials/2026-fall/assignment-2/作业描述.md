# 作业 2：Skills 的使用

## 任务目标

**借助 AI 建立三个对自己有用的 Skills，并实际使用。** 选题不限，例如符合个人偏好的文献检索、个人文件收纳管理，或一项经常执行的科研任务等等，核心是对你自己确实有用。

三个 Skills 可以分别解决不同问题，也可以协同完成一个较大的任务，允许中间由人介入、判断和指挥。请说明各自的职责与划分理由。**但是，把一个简单任务无必要地拆成三个 Skills，这个会酌情扣分。**

可以使用课程推荐的Aether平台开发，也可以使用任何你喜欢用的AI平台来开发，关键是要保留开发和运行的AI对话记录。

## 提交内容

| 内容 | 要求 |
| --- | --- |
| 三个 Skill 文件夹 | 包含 `SKILL.md` 及实际使用的脚本、资料等的完整可运行skill |
| 一份 README | 对每个 Skill 说明：解决什么问题、原来人工怎样做、现在怎样通过 Skill 完成并节省了多少时间；注明必要的人工介入、使用方法 |
| 创建记录（文件夹） | 提交三个 Skills 各自创建过程的完整 AI 对话，包括相关的调试与修改 |
| 运行记录（文件夹） | 每个 Skill 必须至少提供一个你使用该skill完成对应任务的完整运行对话记录，附必要的输入与输出文件（但是提供的此类文件总大小不要超过100MB，比如数据类只要提供部分示例即可） |

**每份创建或运行记录注明：模型、平台、成本开销（平台显示的 token 或API-Key费用）。** 未显示的数据写“平台未提供”；估算值注明依据。

多个 Skills 在同一大型任务会话中创建或协作运行，可以共用一份完整记录，标明每个 Skill 对应的位置与作用，无需重复提交。

记录应保留对应任务从开始到结束的用户消息、AI 回复。可以导出为markdown或PDF文档，不能只交摘要或结果截图。

**切记！！！提交前对会话记录中你的隐私数据和密钥脱敏（或用占位符替代），保留过程的可理解性。**

如果参考了已有 Skill 进行改进时，在 README 中注明来源、具体修改及其与个人需求的关系。

## 评价重点

- Skill（对于你自己）的实用价值。
- Skill 是否能比较好地完成任务。

和第一次作业提交一样，请在服务器上的个人目录下建立一个“homework2”文件夹，然后将提交内容放置在该文件夹下。

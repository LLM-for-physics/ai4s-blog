# 02 · Skill 怎样使用

一般过程是：**让平台识别 Skill → 提供任务和输入 → AI 按说明执行 → 检查结果。**

使用前，确认所选 AI 平台支持 Agent Skills；普通聊天窗口不一定具备这项能力。下面用已有的 `note-review-cards` 示例演示。

## 1. 放到平台能找到的位置

不同平台可能通过上传、安装或指定目录加载 Skills。以 Aether 的项目目录为例，把本资料中的 `note-review-cards` 文件夹整体复制到：

```text
你的练习项目/
└── .aether/
    └── skills/
        └── note-review-cards/
            └── SKILL.md
```

在 Aether 中打开这个练习项目，再新建会话；如果仍未识别，重新打开项目后检查。目录应位于 **Aether 实际运行的机器**上：在服务器运行时，只复制到自己电脑上不会自动同步。

平台通常先获取 Skill 的名称和描述，选用时再读取正文及所需资源。可通过平台提供的 Skills 列表、加载记录或工具记录核对是否识别成功。

本例路径依据 [Aether 的 Skill 加载实现](https://github.com/Science-Discovery/Aether/blob/dev/packages/opencode/src/skill/index.ts)；其他平台按各自文档操作。不清楚操作方法时，可以请 AI 查阅所用平台的官方文档，并通过实际加载记录核对。

## 2. 点名调用，并提供输入

在对话中发送：

> 请使用 note-review-cards 这个skill，把以下笔记整理成复习卡：
>
> 欧姆定律：导体温度等条件不变，U=IR。  
> 串联：电流处处相等，R总=R1+R2。  
> 相关系数：笔记写 0.9，草稿写 0.6，待核对。

这里，`note-review-cards` 指定处理方法，后面的笔记是本次任务的输入。以后换一份笔记，仍可使用同一个 Skill。

平台也可能根据任务描述自动选用合适的 Skill。刚开始练习时，明确点名更便于检查。

## 3. 检查有没有按规则完成

你应看到按主题整理的问答卡：欧姆定律保留适用条件，串联电阻保留公式，相关系数的矛盾放到“待核对”，而不是任选一个数作为答案。

同时检查 Skill 的加载或调用记录。**仅凭 AI 说“我用了 Skill”，不能确认已正确加载。** 如果没有识别，先检查文件位置、文件名是否为 `SKILL.md`、元数据格式及平台是否启用了它。

Skill 也不会自动赋予 AI 新工具。例如，文献检索需要平台提供搜索能力或者skill自己配置相应的能力；脚本需要对应的运行环境。加载成功后，仍要检查任务是否实际完成。

使用外部 Skills 前，先阅读[其他提示中的使用注意事项](../其他提示.md)。本简单示例用于学习操作，自己的作业应围绕个人需求设计。

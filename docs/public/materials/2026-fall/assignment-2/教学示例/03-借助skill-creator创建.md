# 03 · 借助 skill-creator 创建

**你负责说明需求和判断结果，AI 借助 skill-creator 整理规则、生成文件，再根据反馈修改。** 通常不需要从空白文件开始手写 `SKILL.md`。

`skill-creator` 本身也是一个 Skill，专门指导 AI 创建和改进其他 Skills。它与最终做出的 `note-review-cards` 分工不同：前者帮助制作，后者用于日常整理笔记。

## 1. 确认 skill-creator 可用

优先使用所用平台自带或推荐的 skill-creator，在平台的 Skills 列表或加载记录中确认。没有时，先按平台文档安装兼容版本；**只在对话里提到这个名字，不会自动完成安装。**

可参考 [Anthropic 官方 skill-creator](https://github.com/anthropics/skills/tree/main/skills/skill-creator)。如果通过复制文件安装，应保留其引用的脚本和资料，核对所需工具是否适用于自己的平台，不能只复制一个 `SKILL.md` 就默认完整可用。放置目录的方法见[上一篇](02-Skill怎样使用.md)。

## 2. 用自然语言说明需求

可以直接把一个需求交给 AI，也可以先与 AI 做一次真实任务，逐步说明偏好，再把满意的方法整理成 Skill。

以下是请求示例，使用时替换为自己的任务：

> 请使用 skill-creator，帮我创建一个整理学习笔记的 Skill，命名为 note-review-cards。
>
> 我每周都会整理笔记，希望按主题生成问答复习卡，每张卡只问一个问题。答案尽量简短，但要保留公式和必要条件；有矛盾或尚未确认的内容，单独放到“待核对”。只整理我提供的信息，不补充外部知识。
>
> 我会提供一小段笔记用于试做。请先和我确认还缺少什么信息，再生成所需文件，说明保存位置和使用方法。

想清楚**平时做什么、输入是什么、希望得到什么、有哪些个人偏好**，就可以开始。暂时拿不准的地方，可以请 AI 提出选项或先试做一版。

如果此前已经做出满意的结果，可以直接说：“请使用 skill-creator，把刚才的方法和我的偏好整理成可复用的 Skill。”注意保留通用规则，让每次的笔记作为新输入，不要把某次笔记写成固定答案。

## 3. 查看生成物，确认能使用

AI 应生成实际的 Skill 文件夹。打开 `SKILL.md`，看看用途、处理方法和输出规则是否符合自己的要求；如果附带脚本或资料，也应知道它们的作用。

可以继续请 AI：

> 请说明这个 Skill 的文件结构、保存位置和所需工具，并检查它是否已放在当前平台能识别的位置。

**生成文件后，还需要让平台识别它。** 按上一篇的方法加载；如果 AI 已直接保存到正确目录，就无需重复复制。

## 4. 试用，并把反馈写回 Skill

建议新建会话，用一个小输入点名调用新 Skill，观察它能否在没有前面讨论记录的情况下完成任务。使用笔记示例时，检查公式、条件和疑点是否处理正确。

发现问题后，向 AI 提出具体反馈。例如：

> 这次把两个不同问题放进了同一张卡。请使用 skill-creator 修改 note-review-cards，使每张卡只问一个问题；必要时拆成多张。请更新文件，再试一下。

修改后按平台要求重新加载，检查问题是否解决。反馈应落实到 Skill 文件里，方便下次继续使用。

以后整理新笔记时，调用 `note-review-cards` 即可；需要改变它的规则时，再借助 skill-creator 修改。

从开始创建时就留意保存对话，完成后按[作业描述](../作业描述.md)整理创建记录、运行记录和相关文件。示例提示用于说明方法，实际记录应来自你自己的操作。

创建流程参考：[skill-creator 官方说明](https://github.com/anthropics/skills/blob/main/skills/skill-creator/SKILL.md)。
